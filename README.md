# Codex Computer Use Bridge

Local model routing for native Codex Computer Use on macOS.

Supported picker entries:

- Gemini 3.7 Flash through Antigravity
- GPT-5.6 Sol Instant through the OpenAI API
- GPT-5.6 Sol Fast through the OpenAI API

Codex keeps control of task history, permissions, tool cards, Sky execution,
the pointer, and picture-in-picture display. The bridge handles model planning
and Responses protocol translation.

See [bridge/README.md](bridge/README.md) for installation, tests, and recovery.
